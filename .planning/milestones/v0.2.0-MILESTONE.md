## Key design decision

**Graceful 402 degradation via `resolveOrGate<T>`:** a tier-gated sub-call in a composite marks itself `{ available: false, reason: "..." }` rather than failing the whole call. Non-402 errors still propagate. Proves useful when a Professional-tier user calls `company_deep_dive` — they get everything except the Advisor-only sections.
