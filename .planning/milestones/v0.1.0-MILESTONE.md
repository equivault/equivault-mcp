## Infrastructure shipped

- TypeScript MCP server scaffold (`@modelcontextprotocol/sdk` ^1.29.0, zod ^3.25.0)
- `EquiVaultClient` with API key + tenant ID auth; `get()` / `post()` methods
- Tier-aware `translateError` covering 401 / 402 / 404 / 429 / 5xx
- `handleError` helper shared across all tool modules (refactored to shared module in Task 14)
- GitHub Actions CI (Node 18/20/22) + tag-triggered `Publish to npm` workflow
- README with Claude Desktop + Claude Code setup, tools table, examples
