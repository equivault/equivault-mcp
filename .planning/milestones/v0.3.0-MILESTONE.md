# equivault-mcp v0.3.0 — EquiVault Complete

**Shipped:** 2026-04-17
**Platform tracked:** v1.5.x (signals + alerts + briefs + portfolios + media + gurus + markets)
**Tag:** https://github.com/equivault/equivault-mcp/releases/tag/v0.3.0

## Scope

Expose every EquiVault capability that goes beyond fiscal.ai — signals intelligence, alerts management, automated briefs, portfolio analytics, media/transcripts, guru tracking, markets. Close the feature gap so an MCP user sees everything a paying EquiVault user sees.

## Tools added (16 → 38 total)

**Signals (5):** `get_signals`, `get_signal_summary`, `get_signal_dashboard`, `get_signal_trends`, `get_trending_signals`

**Alerts (3, Advisor+):** `create_alert`, `update_alert`, `delete_alert`

**Briefs, portfolio, media, gurus, markets (6):**

| Tool | Endpoint | Tier |
|---|---|---|
| `list_briefs` | `GET /briefs` | Starter+ |
| `get_brief` | `GET /briefs/{id}` | Starter+ |
| `get_portfolio_analytics` | `GET /portfolios/{id}/analytics` | Analyst+ |
| `list_media` | `GET /media/items` | Starter+ |
| `get_guru_holdings` | `GET /gurus/{id}/holdings` | Analyst+ |
| `get_markets` | `GET /markets` | All |

**Advanced composites (2):**

| Tool | Orchestrates |
|---|---|
| `morning_briefing` | 3–4 parallel calls: signal dashboard + trending + followed briefs + optional portfolio analytics |
| `research_report` | 16 parallel calls: full deep-dive + recent signals + related briefs |

## Infrastructure change

Added `put()` and `delete()` methods to `EquiVaultClient`. First write-mutation tools in the MCP (alert management). Follow the same auth + error-handling contract as `get()` / `post()`.
